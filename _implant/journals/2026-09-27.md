# 2026-09-27

## Vocabulary: an implant is not a brain

erkkimon restated the rule: brainpick registers one repository as the
**cortex**; every other registered repository (or its subfolder) is an
**implant**, and every `brain-implant-*` repository keeps its data under
`_implant/`, never `_brain/`. This repository already used `_implant/`; the
remaining slips were in wording — config comments in `brainpick.toml`,
`henxels.yaml` (and the generated AGENTS.md), `henxels_checks.py`, the README
("the agent's own brain" → "the agent's cortex"), and the subsidiarity
section of [Using the brain implant](../skills/using-the-brain-implant.md).
Recorded as a standing rule:
[An implant is not a brain](../conventions/an-implant-is-not-a-brain.md).
brainpick's own names (`brain_*` tools, the `[brain]` table, `brain://`) stay.
