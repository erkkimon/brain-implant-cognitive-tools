## Founding decisions — erkkimon

The cognitive-tools implant is founded as a public brainpick brain implant
holding tools that "support LLMs' cognitive capabilities and remove LLMs'
architectural blind spots" — shared by domain implants rather than copied
into each. Name agreed today. The brief, distilled into the
[manifest](../vision/manifest.md):

* **The Bayesian calculator is the first tool.** An agent talks with the
  user, applies its knowledge, elicits the factors, and calculates an
  "educated gut feeling"; the model is handed back so the user can change
  the inputs and replay
  ([Estimate a credence](../skills/estimate-a-credence.md),
  [Credence is a model, not a measurement](../conventions/credence-is-a-model-not-a-measurement.md)).
* **A worked example is a provocation** — "brutalistically" so: its
  numbers exist to nudge people and agents to do a better calculation from
  their own beliefs (`skills/tools/models/example-provocation.appraisal.json`).
* **Compute, never guess** — numbers a tool could produce come from the
  tool ([Compute, never guess](../conventions/compute-never-guess.md)).
* **Skills say "brain implant"**: a brain is cortex plus implants; either
  alone works slightly lobotomised
  ([Using the brain implant](../skills/using-the-brain-implant.md)).
* **Public from the first commit**, pull requests welcome, no personal
  details; tooling MIT, documentation CC BY-SA 4.0; decisions attributed
  to "erkkimon" ([Written to be public](../conventions/written-to-be-public.md)).
* **Git**: the agent never stages or commits; the founder reviews.
